# 后端代码说明

## 一、目录总览与启动入口

本目录是Java8、Spring Boot 2.7.18、Orekit 12.0的Maven工程。服务入口为[SpaceTargetVisibleApplication.java](src/main/java/com/runisys/orbit/spacevisibility/SpaceTargetVisibleApplication.java)。

```text
backend/
├─ pom.xml                       版本、依赖及Spring Boot打包插件
├─ maven-repository/             随包提供的Maven依赖与构建插件
├─ maven-settings.xml            随包离线构建配置
├─ orekit-data/                  星历、地球定向、闰秒等运行基础数据
├─ db/
│  ├─ mysql/schema.sql           MySQL建表脚本
│  └─ dameng/schema.sql          达梦建表脚本
└─ src/main/
   ├─ java/
   │  ├─ com/runisys/orbit/spacevisibility/
   │  │  ├─ SpaceTargetVisibleApplication.java  应用启动
   │  │  ├─ api/                正式HTTP控制器、DTO和异常处理
   │  │  ├─ application/        业务流程、任务及文件编排
   │  │  ├─ domain/             轨道、几何、载荷、窗口及下传计算
   │  │  └─ infrastructure/     数据库、文件存储和运行配置
   │  ├─ com/tx/alg/            弹道窗口计算与轨迹拟合实现
   │  └─ db/migration/          Flyway Java迁移
   └─ resources/
      ├─ application.yml        服务、数据库、计算和文件参数
      ├─ application-demo.yml   H2演示环境配置
      ├─ db/migration/          Flyway SQL迁移
      └─ orekit-data/           类路径闰秒数据
```

建议按“api入口 → application流程 → domain或com.tx.alg计算 → infrastructure数据读写”的顺序阅读一个功能。

空间目标规划由application编排并调用domain；弹道由application/ballistic编排，调用com.tx.alg及domain公共工具。已有空间功能的工程，具体增量目录、公共依赖和Spring接入步骤见[弹道增量代码集成说明](../docs/弹道增量代码集成说明.md)。

## 二、HTTP入口：api

### 2.1 空间目标

| 控制器/定义 | 主要职责 |
| --- | --- |
| SpaceVisibilityController | 卫星、载荷、地面站、目标查询及同步规划等空间接口 |
| PlanningTaskController | 异步规划任务提交、状态、结果与取消 |
| VisibilityTaskResultController | 任务结果记录、明细、备注及选窗结果 |
| SpaceApiModels | 空间接口请求/响应定义 |

### 2.2 弹道目标：api/ballistic

| 控制器 | 路径/职责 |
| --- | --- |
| BallisticVisibilityController | /api/orbit/visibility/search，可视窗口搜索 |
| BallisticFitController | /api/trajectory/fit/package102，102包拟合 |
| BallisticSimulationController | /api/trajectory/simulate，系统模拟 |
| BallisticRetimeController | /api/trajectory/retime，弹道文件重定时 |

## 三、业务流程：application

### 3.1 空间规划与记录

- ReferenceDataService：卫星、地面站、目标及载荷等基础目录。
- PlanningFacadeService：接收规划参数，组合下传与观测计算能力。
- DownlinkPlanningService、DownlinkWindowValidator：下传计算、链路处理与窗口校验。
- VisibilityPlanningService、VisibilityConstraintPlanner：目标/卫星配对计算与约束规划。
- OrbitStateProviderFactory、OrbitPositionCache：构建轨道状态提供器，并复用查询结果。
- PayloadConstraintFactory、ObservationSampleEvaluator：载荷约束构造与观测样本判定。
- PlanningTaskService：后台任务生命周期、进度和取消。
- VisibilityTaskResultService、WinToolReportFormatter：结果保存、读取与摘要整理。

### 3.2 弹道编排：application/ballistic

- BallisticVisibilityService：请求转换、目标文件加载及窗口搜索调用。
- BallisticFitService、BallisticSimulationService、BallisticRetimeService：三类弹道处理的输出目录和算法调用。
- BallisticTrajectoryService：管理本地/远程弹道源的读取作用域和解析。
- BallisticFileService：上传登记、结果登记、分页预览和下载业务。

## 四、计算与约束：domain

```text
domain/
├─ orbit/       轨道定义、状态、外推工具及空间/弹道实现适配
├─ geometry/    向量、地面站几何及坐标转换
├─ time/        时间基准转换
├─ payload/     标准载荷、光照/太阳约束与样本判定
├─ window/      时间扫描、区间归并和共同观测窗口
└─ downlink/    地面站下传规划与光照要求
```

轨道阅读入口是OrbitDefinition、OrbitTime、OrbitState及OrbitPropagationTool。SpaceOrbitStateProvider、TleOrbitStateProvider、KeplerOrbitStateProvider提供对应空间轨道状态，BallisticOrbitPropagation、BallisticCartesianPropagation连接弹道外推实现。OrbitPropagationTool统一查询入口，具体模型由对应实现执行。

OrekitDataInitializer定位外置orekit-data并初始化计算数据；SpaceTimeFrames和geometry中的坐标工具负责各自坐标口径。参数或算法修改应同时核对时间、坐标、位置速度单位和输入约束。

## 五、弹道计算：com.tx.alg

### 5.1 可见窗口

公开调用入口是[OrbitCalculator.java](src/main/java/com/tx/alg/OrbitCalculator.java)，请求定义在com.tx.alg.api.VisibilityRequest。实现按职责展开为：

| 实现 | 职责 |
| --- | --- |
| BallisticLaunchSearch | 发射偏移搜索、目标/卫星/载荷遍历与结果汇总 |
| BallisticSampledWindows | 目标采样与连续可见窗口计算 |
| BallisticTrajectoryReader | CSV/Excel轨迹读取、时间和坐标列解析 |
| BallisticVisibilityGeometry | 可见性几何及载荷相关判断 |
| BallisticArcSupport | 可见弧段辅助处理 |
| BallisticResultWriter | 结果结构的JSON写出 |
| TrajectoryFileResolver | 本地、HTTP/HTTPS及MinIO文件源解析 |

com.tx.alg.api中保留计算DTO和Java兼容调用。Spring Boot的正式弹道HTTP入口位于com.runisys.orbit.spacevisibility.api.ballistic。

### 5.2 拟合、模拟和重定时

[TargetTrajectoryFitter.java](src/main/java/com/tx/alg/trajectory/TargetTrajectoryFitter.java)包含三类计算入口及其请求/结果类型：

1. fitPackage102ToCsv：按目标解析102点，处理原始点约束、插值与外推，生成弹道CSV。
2. simulateToCsv：按起落点及时间约束模拟弹道，生成CSV。
3. retimeTrajectoryToCsv：按新发射时间重算时间与惯性系列，生成重定时CSV。

方法签名、102当量、CSV字段和输出约定见[目标轨迹拟合接口](../docs/TARGET_TRAJECTORY_FIT_API.md)。

## 六、数据与文件：infrastructure

- persistence/entity、persistence/mapper：卫星、地面站、目标和任务记录的MyBatis Plus实体及Mapper。
- persistence/DemoDataInitializer：demo环境的基础目录初始化。
- files/BallisticFileStorage：上传文件、临时文件、结果文件、元数据及生命周期。
- files/BallisticFileConfiguration：文件目录、限额、TTL和清理任务配置。
- config/MybatisPlusConfiguration：数据库分页等配置。
- web：Tomcat运行配置。

SQL迁移与Java迁移共同维护数据库结构。查数据库字段时从entity和迁移文件对应阅读；查上传/下载问题时从BallisticFileController、BallisticFileService追到BallisticFileStorage。

Maven库使用、构建和启动命令见[源码包说明](../源码包说明.md)。
