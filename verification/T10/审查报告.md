### 已关闭 P2：首次同实例乱序验证实际上每行新建实例

首次审查时的位置：`backend/src/test/java/com/runisys/orbit/spacevisibility/domain/orbit/BallisticOrbitBindingTest.java:20`、`:36`、`:39`、`:40`；来源位置 `verification/T10/OriginalPropagationProbe.java:63`、`:68`。以下保留首次发现轨迹，行号对应修复前版本。

本次审查用只读 Python 读取黄金并按测试原 key 计算，实际输出：`rows=72; current test instance groups=72; intended orbit groups=6`。因此验证报告第34行关于同历史、重复和乱序查询逐bits一致的断言，当前测试并未证明。纯 Java 示例固定真实 offset=0，其已有数值对照结果仍有效；此问题不否定既有位置黄金。
