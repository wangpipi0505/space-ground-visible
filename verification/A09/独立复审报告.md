# A09 STK 标准载荷验证独立复审

复审日期：2026-10-15  
结论：**Spec Pass / Quality Approved**，无未解决的 Important 或 Minor 问题。  
审查范围：STK Access 自动化、STK/Web 复算脚本、验证报告、保存场景证据及本项验证范围。

## 复核结论

- 确认 STK 角速度复算从实际 `Constraint Data.FromAngularRate` 导出。首轮报告曾用默认 VVLH AER 导数合成角速度，属于错误参考系；修订版已移除该数值，改用 STK Access 约束实际值。
- 复核 Web 有限差分按软件真实采样历元及相邻点实际秒数计算。时间字段保留原始数值，仅状态表索引使用 6 位小数；SAT_B C3 末点与 STK 结束时间偏差 0.0000002145767439 秒，JSON 与报告均披露。
- 角速度配对结果为 C3/C4：SAT_A 488/196 点，SAT_B 272/50 点。最大绝对速率差分别为 SAT_A C3 0.000531240°/s、C4 0.000438381°/s，SAT_B 两项均 0.002220063°/s；各组均未超过 0.3°/s。
- 确认 C0—C5 共 12 组、10,284 个 Web 样本在 20 微秒边界容差内与 STK 连续 Access 判定一致，C4 窗口边界及 AER 几何误差与报告一致。
- 太阳方向与遮挡规则差异已说明：Web 弹道分支使用 J2000 解析太阳方向并持续规避；STK 使用观测者表观太阳方向，且在地球遮挡太阳时豁免 LOS Sun Exclusion。
- 复核报告明确本次 Web 与 STK 共用同一组星历输入，故本测试只验证载荷判定与 Access/AER 对照。独立 STK 轨道传播和外部真值位置/速度精度未测，未把软件自身轨迹当作 STK 参考真值。
