## 验证目的与范围

本次只比较“同一组卫星/弹道轨迹状态下，Web 标准载荷约束与 STK Access 的可见窗口判定”。卫星与目标星历都从软件本次实际状态导出后共同导入 STK，故本报告能验证坐标、距离和窗口约束的对照，**不能作为 STK 独立外推或外部绝对轨道精度报告**。没有把 Web 可见窗口导入 STK；所有 STK 窗口均由 STK Access 重新计算。

固定发射偏移为 2880 秒，即 2026-07-01 08:45:00 UTC；目标源时间为 2026-07-01 07:57:00 UTC。Web 样本间隔为 1 秒，末点另含 855.9000002145767 秒；STK 采用相同 UTC 范围，Access 固定步长 1 秒，事件时间收敛阈值 0.00001 秒。连续窗口与 Web 样本按 0.00002 秒容差逐点匹配。此次没有重跑 361 个偏移的最优时间搜索。

## 载荷字段与 STK 设置

本次真实 HTTP 请求中的标准 SPACE 载荷为：

| 字段 | Web 值 | STK Access 设置 |
| --- | ---: | --- |
| 最近探测距离 | 1000 km | Range Min 1,000,000 m |
| 最远探测距离 | 4000 km | Range Max 4,000,000 m |
| LVLH 方位角 | 90°–270° | Azimuth Angle Min 90°，Max 270° |
| LVLH 俯仰角 | −90°–0° | Elevation Angle Min −90°，Max 0° |
| 跟踪角速度 | 0.3°/s | Angular Rate Max 0.3°/s |
| 太阳回避半角 | 90° | LOS Sun Exclusion 90° |
| 地球遮挡 | 椭球 LOS | Line Of Sight 开启 |
| 启动角速度 | 0.07°/s | 仅保留在 Web 请求；该字段是元数据，不参与窗口计算 |

STK 卫星默认 AER 坐标为 VVLH CBI：X 沿速度方向，Z 指向地心；STK 方位正向和 Web 的 N = R × T 方位定义相反，而俯仰的正方向一致。因此对不对称方位窗使用 Az_STK = (360° − Az_Web) mod 360°。默认 90°–270° 关于 180° 对称，转换后数值仍为 90°–270°。这一坐标关系依据 STK 官方 [Access Coordinate Frames](https://help.agi.com/stk/content/stk/AccessCoordinateFrame.htm) 文档，并用 C5 非对称窗口实际核对。

本次没有配置圆锥或矩形传感器 FOV；载荷方位/俯仰按 Satellite 对象上的 Access 角约束设置，以对应 Web 的两个独立 LVLH 角范围。

C0–C4 逐项增加约束；C5 专门核对非对称方位转换。每组均比较了 857 个 Web 样本时刻、两颗卫星。Web 共 10,284 个布尔样本，STK Access 连续区间在相同采样时刻求值。

| --- | --- | ---: | ---: | ---: |
| C0 | 仅 LOS | 1 / 1 | 719 / 854 | 0 |
| C1 | C0 + 距离 1000–4000 km | 1 / 2 | 521 / 653 | 0 |
| C2 | C1 + 方位 90–270°、俯仰 −90–0° | 1 / 1 | 488 / 272 | 0 |

## 已发现的定义边界

1. **角速度定义不同，但本组阈值判定相同。** Web 对软件实际 1 秒采样序列使用相邻视线夹角除以实际间隔；STK 车辆 Angular Rate 使用惯性坐标系下表观相对位置与速度计算。官方 [Angular Rate 约束定义](https://help.agi.com/stk/Content/stk/constraints-07.htm) 与 [Angular Rates 报告数据源](https://help.agi.com/stk/SubSystems/dataProviders/Content/htmlStyles/Access/Reports/Angular_Rates.htm) 说明该值由 Access 的 `Constraint Data.FromAngularRate` 提供。本次已直接导出该字段，没有再用旋转 VVLH AER 导数代替 STK 约束值。

   | 条件 / 卫星 | 配对样本 | Web 有限差分最大值 (°/s) | STK FromAngularRate 最大值 (°/s) | 两者最大绝对差 (°/s) | 平均绝对差 (°/s) |
   | --- | ---: | ---: | ---: | ---: | ---: |
   | C3 / SAT_A | 488 | 0.294398434 | 0.294399112 | 0.000531240 | 0.000288378 |
   | C4 / SAT_A | 196 | 0.294398434 | 0.294399112 | 0.000438381 | 0.000182468 |
   | C3 / SAT_B | 272 | 0.289223185 | 0.287003122 | 0.002220063 | 0.000386443 |
   | C4 / SAT_B | 50 | 0.289223185 | 0.287003122 | 0.002220063 | 0.001400648 |

   四组 Web 与 STK 配对样本中，两边均没有超过 0.3°/s 的点，故这组参数下角速度约束未造成布尔窗口差异；最大实测速率差为 0.002220063°/s。由于 STK 瞬时率和 Web 相邻样本有限差分的定义不同，本结果只确认本组输入和阈值下判定一致，不能推导为任意采样率/轨迹下完全等价。STK 的 Data Provider 原始输出位于 ignored verification/runtime/A09/stk-results-rerun/C3-* 与 C4-* angular-rate.csv。
2. **太阳方向与遮挡策略不同。** Web 弹道分支使用现有 J2000 解析太阳方向向量并始终执行回避；STK 按观测者的表观太阳方向评估 LOS Sun Exclusion。STK 官方 [Sun Constraints](https://help.agi.com/stk/Content/stk/constraints-02.htm) 说明：当地球遮挡太阳方向时，LOS Sun Exclusion 不施加该排除约束。本次 C4 的所有离散点仍完全一致；其他日照/遮挡几何下不能直接假设策略一致。
3. **没有独立传播器对比。** 本次 STK 与 Web 共用从软件状态生成的 .e 文件，隔离测试了载荷几何与 Access 求值。绝对外推精度应单独用相同初始状态、独立 STK 传播器及外部真值进行测试；此处没有以软件输出冒充 STK 输出。

## 结论

在本次固定轨迹、固定发射时刻与载荷参数下，STK 实际 Access 与 Web 离散可见性样本在 20 微秒比较容差内全部一致；范围最大差为 0.000990 m，角度最大差为 1.48×10⁻⁷°。完整载荷对应 Web 196 点与 50 点两个窗口，STK 连续边界与 Web 采样边界相差不足 1 秒。角速度定义虽不同，但四组样本判定一致且速率最大差为 0.002220063°/s；太阳遮挡策略也存在差异，因此结论限于本组已测输入。本报告不替代独立轨道传播精度或原始 STK Access 真值测试。
