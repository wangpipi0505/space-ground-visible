日期：2026-10-15

范围：仅前端组件、样式与对应回归测试  
代码分支：`codex/ballistic-workbench-ui`

## 问题与改动

检查发现，空间目标页面已统一使用全局注册的 Element Plus；弹道迁入的多个页面仍直接编写原生 `input`、`select`、`button`、`table`，并以自定义 CSS 修饰。原因是迁移实现没有完成组件库对齐，不是接口或计算逻辑的限制。

本次把弹道窗口、卫星/载荷编辑、拟合、模拟、重定时、轨迹分页与结果表统一改用 Element Plus 的 `el-form`、`el-input`、`el-select`、`el-option`、`el-upload`、`el-button`、`el-checkbox`、`el-table` 和 `el-table-column`。样式改为作用于 Element Plus 控件，同时保留现有卡片、字段顺序和页面区域布局。

替换组件时同步适配 `update:model-value` 和 `UploadFile.raw` 事件，保留数值清空、文件上传及服务端引用规则。窗口/拟合/模拟/重定时请求字段、文件格式、校验条件、计算算法和结果结构均未改变。更新原组件测试，使断言操作 Element Plus 控件并继续覆盖原请求与状态行为；新增源码一致性测试，防止弹道业务页面重新引入原生表单和表格标签。
