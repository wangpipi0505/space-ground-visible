# T08 独立轨道外推工具入口验证

2026-10-13，基于 T07 `231e5f4` 执行。本条仅定义并验证普通 Java8 工具入口，不更新台账完成状态、不提交。

## 实现边界

产品源码新增 `domain/orbit` 下四个纯 Java 文件：`OrbitTime`、`OrbitDefinition`、`OrbitState`、`OrbitPropagationTool`。只依赖 Java8 标准库及既有 `Vector3`。定义以不可变字段显式描述原参数、模型、历元/查询时刻、输入及输出坐标和单位。工具以一个简单原生适配接口绑定实现，不建立注册中心、插件框架或通用 Orekit 模型。

- 空间 `TLE_SGP4` 保留原 SGP4/SDP4 选择，TLE 第一行内嵌 UTC 历元原文不重新解析/量化，输出 TEME。空间业务 `KEPLER_6` 在定义中明确标为 `SPACE_KEPLER_J2_RK4`：EME2000 二体加 J2、原 RK4 步长（默认10秒），输出 TEME。
- 弹道 `TWO_BODY`、`J2_SECULAR`、`J2_NUMERICAL` 只定义六根数入口，保留原 a/e/i/RAAN/近地点幅角/平近点角，位置米、角度度，原 J2000 输出。步长参数0表示继续使用各原算法内部策略，不增加新的弹道积分配置。
- 拟合区间外只定义原 J2000 端点位置米、速度米/秒和原生端点时刻，标注原二体 RK4 最大步长1秒；未迁入拟合/插值算法。
- 时间分为 `UTC_INSTANT` 和 `LEGACY_J2000_SECONDS`。后者是旧 UTC 日历自2000-01-01中午计秒及原 `utcOffsetSec` 约定，不是 Orekit J2000 TT；保存原始 double，禁止隐式往返 Instant。frame 不匹配、时间口径不匹配或 offset 约定不匹配在调用适配器前拒绝，不做暗中转换。
- `positionAt`、`velocityAt` 各自只调用对应原方法。只有调用者显式请求 `stateAt` 时才依次查询位置和速度。原 provider 默认速度 ±1秒中心差分和线程缓存策略保持不变。适配器异常原样抛出。

原 `OrbitStateProvider`、两种空间 provider、应用工厂、HTTP/Java 既有接口均未修改；生产业务尚未绑定新工具。空间业务工厂接入留到 T09，弹道原实现迁入留到 T10，集中坐标转换适配留到 T12。绑定者须保证适配器使用定义中的同一参数/模型；工具不解析第三方传播器内部状态以猜测或核验其配置。
