# T09 空间传播实现接入验证

2026-10-13，基于 T08 完成提交 `9058e58`。本项仅将空间生产传播入口接入公共工具；本报告不更新台账完成状态、不提交、不执行 T10。

## 实现及兼容边界

新增单个纯领域 `SpaceOrbitStateProvider`，以原 `OrbitStateProvider` 接口桥接公共 `OrbitPropagationTool`。应用 `OrbitStateProviderFactory.fromSatellite/fromTarget` 保留原签名、模型分支、缺参检查、`BigDecimal.doubleValue()` 顺序及 `LocalDateTime.toInstant(ZoneOffset.UTC)` 转换，只将构建入口改为领域桥。有效位置查询真实调用 `Tool.positionAt`；有效速度查询真实调用 `Tool.velocityAt`，原 provider 的 `velocityAt` 仍先取 t−1秒位置，再取 t+1秒位置并乘0.5。生产位置路径没有改用 `stateAt` 或追加速度计算。

桥持有一次构建的原传播实例；原 `TleOrbitStateProvider`、`KeplerOrbitStateProvider`、`OrbitStateProvider` 源码及构造器、公开方法全部未改。TLE 保留 SGP4/SDP4 自动选择和 Alpha5 编号遮蔽，工具定义保留两行原文。六根数定义明确为 `SPACE_KEPLER_J2_RK4`，输入 EME2000、输出 TEME，半长轴米、角度度、原平近点角及 UTC 纳秒历元不变；原二体+J2 固定步长 RK4、默认10秒/配置步长、60秒锚点、8192上限及 ThreadLocal 缓存策略均由原实现继续维护，桥不增加缓存、不重建每次查询的传播器。

原始参数入口先构建原 provider，再构建定义，避免定义对历元或步长的新检查替换旧错误。应用层模型/缺参仍抛出“轨道模型或轨道参数无效”；原六根数/步长错误仍为“六根数轨道或RK4积分步长无效”；非法 TLE 仍为“TLE 两行根数格式无效”。TLE 不检查无关 RK4 配置。旧接口 null 查询是失败兼容路径，直接交原 provider 抛出原异常，避免 `OrbitTime.utc` 的新增 null 检查改变旧异常；正常查询全部经工具。

普通 Java 可用 `SpaceOrbitStateProvider.fromDefinition(definition).tool()` 从 TLE 或空间六根数定义创建真实工具，并显式查询位置/速度/完整状态；弹道/笛卡尔定义明确拒绝。没有增加插件注册、转换框架或依赖，没有修改弹道、数值公式、语言版本或前端锁文件。

## 红灯与接入回归

先新增应用接入断言再执行 Java8 Maven。实际运行失败为：期望生产工厂返回 `SpaceOrbitStateProvider`，实际仍为 `KeplerOrbitStateProvider`；1项、1失败、0错误，见 `integration-red.log`。随后先增加领域回归，因尚无领域桥类型而编译失败，见 `domain-red.log`；这是缺失 API 编译红灯，不计为运行断言失败。实现后初轮7项通过，见 `integration-green.log`。最终扩展为10项新增接入测试：领域6项、应用4项。

真实对照使用独立同参原 provider 与桥/工具，不让同一个可变实例先后执行两套历史。查询顺序为 offset `[0,60,120,59,59,-3,3600,3601]` 秒，各时刻额外 `+7ns`；每轮先位置后速度，覆盖锚点边界、重复、回退、历元之前、正向及非整秒查询。领域对照最后另用 `+3602秒+13ns` 显式状态，原实例同样先位置后速度。每个位置/速度的 x/y/z 用 `Double.doubleToRawLongBits` 精确比较，不改变旧断言或容差。

- 领域真实对照4组：标准 TLE、Alpha5 TLE、10秒空间六根数、3.5秒空间六根数，共72个向量/216个坐标 bits。
- 应用真实对照4组：卫星六根数10秒、目标六根数3.5秒、卫星 Alpha5 TLE、目标 Alpha5 TLE，共64个向量/192个坐标 bits；同时检查定义模型、frame、根数、UTC纳秒历元和步长映射。
- 记录型原 provider 检查：一次位置只有一次原位置调用，没有速度；一次速度只有一次原速度调用，随后按 t−1、t+1 顺序各一次原位置调用，总计3次位置/1次速度。错 frame 在工具边界拒绝，原调用次数不增加。
- 保留模型/缺参、非法数值、无效配置步长、非法 TLE 和 null 查询的旧错误；TLE 路径用配置步长0验证无关配置不影响旧模型。
