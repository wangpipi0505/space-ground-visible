# A07 拟合三页呈现验证

本组仅覆盖102拟合、端点模拟、重定时与共用结果文件组件。现有唯一JSON草稿、请求适配、上传、登记、预览、完整CSV读取、下载与引用生命周期逻辑未变；三页增加固定结果区与运行状态，常用操作改为简短文案，技术详情和CSV预览默认折叠。重定时null选项仍可在高级设置访问。

- `setup-failure.*`：首次隔离cwd运行时，用URL定位fixture触发测试基础设施错误，没有测试执行；不能作为业务RED。
- `red.*`：修正为按测试文件目录解析fixture后实际运行，3个新增初始结果区用例因缺少结果面板失败，13个已有回归通过。此时尚未改产品代码。
- `green.*`：三页模板和结果组件调整后3个文件、16个测试通过。
- `green-final.*`：补充结果区等待/成功/失败和文件详情默认折叠断言后，3个文件、16个测试通过。

每组JSON记录UTC开始/结束、真实Node argv、ignored运行cwd、子进程exitCode、源文件与双流SHA256；stdout/stderr保留真实原流。`run-tests.py`可复跑当前源码；历史元数据校验值用于指明当时被测源码，而非声称后来修改也已覆盖。

HTTP在组件测试中mock，用于核对请求、引用恢复和页面生命周期。未在此子任务执行真实后端物理计算、全前端测试、类型/构建或浏览器截图；这些由主任务整体验证。三个spec的fixture改为相对测试文件解析，允许从指定ignored runtime cwd运行，未改fixture内容。已运行限定改动路径的git diff --check，无空白错误；Git仅提示既有行尾规范化。

文档同步了三个子页按钮名、结果空态、高级JSON/null入口、文件预览与恢复操作。统一样式由主任务集中写入仅弹道根作用域的CSS；本组未改全局样式、计算接口、空间界面或锁文件，未提交Git。
