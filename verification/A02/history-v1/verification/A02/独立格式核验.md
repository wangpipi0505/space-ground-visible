# A02 独立 OpenAPI 格式交叉核验

在实现代理交付文件稳定后，根代理于本机执行固定版本格式验证器，退出码为0，输出为 `docs/openapi/openapi.json is valid`。验证前后文件 SHA256 均为 `bfeb596dcb4dd1879c233bdbc2ec314f62ad97ea18f9763b4a6163a176ddba35`。

```powershell
npx.cmd --yes --package @apidevtools/swagger-cli@4.0.4 swagger-cli validate docs/openapi/openapi.json
```

实际工具版本4.0.4；[命令、退出及字节指纹](external-openapi-check.json)、[原终端输出](external-openapi-check.txt)保存在本目录。仅使用npx缓存，项目依赖与前端锁没有变化。

该工具检查OpenAPI 3.0 schema及规范规则，能力来源见[官方项目说明](https://github.com/APIDevTools/swagger-cli#validate-an-api)。项目已归档，本轮固定版本只用于已有3.0.3合同格式交叉核验。它不替代[业务字段及真实请求响应核验](验证报告.md)，也未执行客户端代码生成。规范语义依据[OpenAPI 3.0.3](https://spec.openapis.org/oas/v3.0.3.html)。
