## 结论边界与保留观察

1. 独立复制 JAR 使用原对地 HTTP 黄金，实际为空窗口；报告明确不将其计作非空窗口验证。非空验证来自真实对空载荷六组合及真实 Tomcat 单目标请求。
2. 默认兼容 Java 入口已委托相同服务，单独比较它不足以证明迁入前后独立一致。显式冻结比较使用 child-first `com.tx.*` 加载原 Controller/算法；本次审查已实际运行该模式，避免仅以两个同源入口相互比较作结论。
3. `http-jit-observation.json` 保留默认真实 HTTP 点1三处 heightM 差，最大 `2E-9 m`。T13 两份原解析器重复调用日志分别记录默认 JVM 256个高度位差、解释执行0差；这支持既有冷热差的关联观察，但不构成对任意请求全部浮点来源的因果证明。本项未通过改容差、格式或黄金掩盖差异；解释执行点1和本次六组合严格通过也不消除该默认 JVM 限制。
4. `utcOffsetSec` 仍为原全局可变字段；其它旧 Java 调用主动并发修改时的隔离未由 T14 解决，已明确留待 T26。符号链接权限跳过也未计作通过。
