# 空间与弹道目标可见性工具

以空间目标可见性软件为底座，集成弹道窗口、拟合、模拟及重定时，采用前后端独立的 B/S 架构。

- 后端：backend，Java 8、Spring Boot 2.7.18、Maven、Orekit 12.0。
- 前端：frontend，Vue 3、TypeScript、Element Plus、Vite，沿用原锁文件。
- 实施记录：[待办事项台账](docs/待办事项台账.md)。
- 编码与提交要求：[开发与提交规范](docs/开发与提交规范.md)。

项目正在按台账逐项实施。运行方法随对应阶段落地；本阶段保留原轨道外推算法，后续再验证 Orekit 底座统一。
