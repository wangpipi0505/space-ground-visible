# 前端代码说明

## 一、工程入口与阅读顺序

本目录是Vue3、TypeScript、Element Plus和Vite工程。建议依次阅读main.ts、App.vue、对应页面、composables、api及utils：先了解界面入口，再跟踪表单状态、请求和结果展示。

```text
frontend/
├─ index.html                    Vite页面入口
├─ package.json                  依赖与dev/build命令
├─ pnpm-lock.yaml                固定依赖解析结果
├─ vite.config.ts                Vue插件、5173端口和/api开发代理
├─ tsconfig*.json                TypeScript工程及类型检查设置
├─ public/
│  ├─ favicon.svg、icons.svg      公共图标
│  └─ samples/                   页面内置弹道CSV
└─ src/
   ├─ main.ts                    注册Vue应用和Element Plus
   ├─ App.vue                    顶层页签、空间工作台及拟合子入口
   ├─ views/                     弹道业务页面
   ├─ components/                表单、载荷编辑、结果表格与轨迹组件
   ├─ composables/               空间工作台和任务记录的状态编排
   ├─ api/                       HTTP请求、请求/响应类型及文件引用
   ├─ utils/                     表单组装、标准载荷校验和默认参数
   ├─ styles/ballistic-workspace.css  弹道工作台布局
   ├─ style.css                  全局样式
   └─ assets/                    代码引用的图片与SVG
```

## 二、顶层页面如何组织

[App.vue](src/App.vue)组织“规划工作台”“任务结果记录”“可视窗口计算”“目标弹道拟合”。拟合页下设“102包轨迹拟合”“模拟弹道”“弹道重定时”。它还把拟合、模拟和重定时产生的文件引用传给窗口页及重定时页。

### 2.1 空间目标规划

空间工作台的主编排位于[useVisibilityWorkbench.ts](src/composables/useVisibilityWorkbench.ts)，页面按以下组件展开：

1. TaskSatelliteSelectionStep：检索卫星、分页和任务卫星选择。
2. SatellitePayloadPanel、StandardPayloadEditor：载荷类型、十字段约束、读取与保存。
3. StationConstraintStep、SatelliteStationLinkPanel：地面站约束和站星链路。
4. DownlinkPlanningStep、WindowSelectionPanel：下传窗口计算与观测时间段选择。
5. TargetSelectionStep、ObservationConstraintPanel：目标筛选及共同观测条件。
6. VisibilityPlanningStep：提交规划、查看进度和展示计算结果。

### 2.2 任务结果记录

TaskResultRecordsPanel显示结果列表，TaskResultDetailDrawer显示明细；useVisibilityTaskRecords负责查询状态。观测结果中的目标勾选、目标弧段合并及确认保存由VisibilityPlanningStep使用useSelectionConfirm处理。

## 三、弹道业务页面

| 页面/组件 | 职责 |
| --- | --- |
| [BallisticPayloadConfigurationView.vue](src/views/BallisticPayloadConfigurationView.vue) | 可视窗口工作台：卫星根数、标准载荷、目标文件、发射偏移搜索及请求提交 |
| BallisticWindowControls | 窗口扫描条件及计算操作 |
| BallisticWindowResults | 最优偏移、全部偏移及目标/卫星/载荷弧段结果 |
| BallisticTrajectoryView | 窗口内目标轨迹和点明细 |
| [BallisticFitView.vue](src/views/BallisticFitView.vue) | 102包输入与拟合参数，调用拟合并登记输出文件 |
| [BallisticSimulationView.vue](src/views/BallisticSimulationView.vue) | 起落点、发射时间、输出间隔及系统模拟 |
| [BallisticRetimeView.vue](src/views/BallisticRetimeView.vue) | 选择已有弹道文件并使用新发射时间重定时 |
| BallisticFitFileResult、BallisticFitTrajectory | 拟合类结果文件、告警、预览下载与轨迹展示 |

三个拟合页面产生的真实文件引用由App.vue汇总；窗口页使用同一引用选择文件，fileId用于预览下载，serverPath用于计算请求。

## 四、HTTP与类型目录

```text
src/api/
├─ client.ts、types.ts           空间接口基础请求及公共类型
├─ visibilityTasks.ts            异步规划创建、状态、结果和取消
├─ visibilityTaskResults.ts      任务记录与明细、备注和选择结果
├─ ballisticHttp.ts              弹道计算/文件辅助接口根及错误处理
├─ ballisticFiles.ts             上传、结果登记、预览、下载和文件引用
├─ ballisticPayloads.ts          标准载荷配置校验回显
├─ ballisticWindow.ts            可见窗口HTTP调用
├─ ballisticWindowTypes.ts       窗口表单、请求、结果类型
├─ ballisticFit.ts               102拟合HTTP调用
├─ ballisticFitTypes.ts          102包、拟合参数及文件结果类型
├─ ballisticSimulation.ts        系统模拟HTTP调用
└─ ballisticRetime.ts            弹道重定时HTTP调用
```

空间默认接口根为/api/v1/space，弹道文件辅助根为/api/v1/ballistic，弹道计算根为/api。环境变量含义与配置方式见[前端载荷配置说明](../docs/前端载荷配置说明.md)。

## 五、表单规则与公共逻辑

| 文件 | 主要内容 |
| --- | --- |
| utils/standardPayload.ts | 空间与弹道共同使用的载荷字段、默认值和输入校验 |
| utils/ballisticWindow.ts | 窗口请求组装、根数/UTC/偏移条件与文件来源校验 |
| utils/ballisticSwingDefaults.ts | 弹道表单采用的默认时间、卫星根数和扫描条件 |
| utils/ballisticFit.ts | 102输入解析及拟合请求组装 |
| utils/ballisticSimulation.ts | 系统模拟表单与请求组装 |
| utils/winToolSummary.ts | 空间规划结果摘要转换 |

典型数据流为“页面表单 → utils校验/组装 → api调用 → 后端响应 → 结果组件”。查某个参数时，可从页面字段追到对应请求类型，再对照接口文档核对单位、默认值和特殊值。

构建及启动命令见[源码包说明](../源码包说明.md)。
