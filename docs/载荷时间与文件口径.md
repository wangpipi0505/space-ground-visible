# 载荷、时间与 CSV 口径

## 十个标准业务字段

空间 `PayloadProfileRequest` 与弹道 `satellites[].payloads[]` 使用同名十字段。SPACE/GROUND去空白、不区分大小写归一；弹道另保留payloadId/payloadName身份，十字段不含身份。空必填字段或非有限数不自动变为0。

| 字段 | 单位/有效范围/特殊值 |
| --- | --- |
| `payloadType` | SPACE对空、GROUND对地；旧中文四类走旧弹道入口，不自动等价 |
| `minDistanceKm` | 公里，必填有限≥0，接口边界乘1000变米且拒绝溢出 |
| `maxDistanceKm` | 公里，必填有限≥0；0不限，非零须>min；距离边界为闭区间，零视线另拒绝 |
| `azimuthMinDeg` | LVLH方位度；双null不限，否则0≤min<max≤360 |
| `azimuthMaxDeg` | 与min成对，不能单端null；倒置端点不表示跨0窗口 |
| `elevationMinDeg` | LVLH俯仰度；双null不限，否则SPACE -90≤min、GROUND -91≤min |
| `elevationMaxDeg` | 与min成对且min<max≤90；GROUND -91是允许输入边界，实际几何俯仰仍在[-90,90] |
| `angleRateDegPerSec` | 度/秒，必填有限；SPACE 0/-1均不限，GROUND 0真零上限且-1拒绝；其它非负 |
| `sunAvoidHalfAngleDeg` | 度，必填有限0..180；0关闭，夹角等于半角允许，小于时拒绝 |
| `startupAngleRateDegPerSec` | 度/秒，可选null/-1禁用；其它非负有限，0/正值仅元数据，当前不进入可见性判定 |

LVLH由径向R、速度垂直R投影T、N=R×T定义，方位`atan2(LOS·N,LOS·T)`归一[0,360)，0度沿速度方向；俯仰`asin(LOS单位向量·R)`，正值背地球。退化速度无法建LVLH，有姿态窗口时不可见，无窗口不强加姿态。跟踪率为相邻真实精选视线夹角/间隔；首点或非正间隔保留原放行/零率约定。

标准距离、角窗口、跟踪率共用 `StandardPayloads/PayloadConstraintMath`；太阳/遮挡上下文分别保留：空间DE405经TEME、WGS84圆柱本影（当前无半影），观测星本影豁免太阳回避；弹道解析近似太阳与旧坐标/遮挡且始终按其太阳规避条件执行。加入GROUND载荷不改变空间生产站点下传、光照或保护规则。

旧 `/payload` 仅对空，米字段 `minDistanceM/maxDistanceM` 保留而拒绝与公里混发；标准profiles保存公里。历史GROUND圆锥仅读取时 `legacyGroundProfile=true` 及旧sensorFullConeAngleDeg/maxDetectRangeKm/sunExclusionAngleDeg回显，应核对标准字段重新保存，不伪造矩形映射。

弹道旧中文圆锥/环形载荷类型、距离≤0不限及旧默认锥角保持。标准载荷的旧响应只真实映射type、maxDistance→maxDetectRange、sunAvoid→sunExclusion，四个锥角字段输出null（不适用）；min距离、LVLH范围、跟踪/启动率无旧摘要字段，完整值由preview返回，禁止加wrapper或填假锥角。root摘要不代表全部多载荷，具体看各payloadResults；计算可见层级不补不可见身份。

## 时间与坐标

空间日期选择器是浏览器Date，提交前 `toISOString()` 转UTC Instant；不能把显示本地时刻直接当UTC。弹道输入是`yyyy/MM/dd HH:mm:ss[.SSS]`或`yyyy-MM-dd HH:mm:ss[.SSS]`字面UTC文本，前端不经Date时区加减。各弹道文件历元独立，显式发射UTC按别名优先级覆盖其自身参考历元。

旧弹道J2000秒定义UTC日历 `2000-01-01 12:00:00` 为零，与Orekit的TT `AbsoluteDate.J2000_EPOCH`不同；同一UTC中午对应TT历元差64.184秒，后续还涉及闰秒。旧秒数不得直接当TT偏移。`utcOffsetSec`保持原兼容语义，HTTP置0；外部旧Java全局可变偏移不能跨请求随意改写。

空间TLE原SGP4/SDP4输出TEME；空间六根数在EME2000中心引力+J2 RK4传播后转TEME。弹道ECI标作原J2000，ECEF按原岁差/章动/恒星时近似链；不等同于所有Orekit坐标变换。位置米，速度米/秒，加速度米/秒²，经纬度度，高度米。

拟合/模拟的ECEF速度保留原STK Fixed旋转约定，与包含地球自转项的地固坐标导数不同。重定时保留来源ECEF位置/速度原单元格，在新UTC经原 `ecefToEciPos/ecefToEciVel` 重算ECI，不能为了看似统一互换速度转换。

## CSV与窗口输出

拟合/模拟原21列按固定次序输出：

```text
YYYY,MM,dd,HH,mm,ss.SSS,ECEF_X,ECEF_Y,ECEF_Z,energy,dt,ECI_X,ECI_Y,ECI_Z,ECI_VX,ECI_VY,ECI_VZ,ECEF_Vx,ECEF_Vy,ECEF_Vz,isOriginal
```

日历UTC/秒文本毫秒；位置格式三位小数m、速度及energy九位小数；energy原`0.5|v|²-μ/|r|`（m²/s²）。这些是CSV舍入位数，不能据此宣称任意内部误差都≤毫米或1e-9m/s。

拟合/模拟 `dt` 是相邻输出点间隔毫秒、首点0；重定时已有 `dt` 改为从新首点起累计毫秒，无dt列不额外添加。`timeIntervalMs` 为相邻间隔毫秒，缺列追加、有列更新，首点0、负间隔按原规则夹为0。重定时保持原表头次序、行序、已有未知列及isOriginal单元格，不裁成21列；未知行尾无表头额外单元格不构成保留的新字段。拟合isOriginal=1表示原始采样硬约束点，生成/外推点不是自动原点；模拟沿原生成标记；重定时只继承来源标记，不因时刻变了就重判原点。

标准窗口参考CSV（8560行）支持原CSV/Excel解析，但缺重定时所要求的某些原ECEF列名；重定时应使用实际拟合/模拟输出或满足该合同的原文件。不能为迁就错误输入改解析算法。

弹道allResults始终按`startOffsetSec+i*stepSizeSec`输入偏移顺序回填；best严格大于累计double时长才更新，并列保留首次。累计时长逐卫星/目标/载荷弧段相加，交叠不去重；非正且有点的旧回退按点数。`finalVisibleWindow`为最早到最晚包络，可含不可见间隔。稳定弧段原门槛至少2点且≥1e-3秒、退出滞回1e-6度，point0仅去点数组而保留统计。手写JSON有限double保留九位小数，NaN/Infinity成null。

空间组合窗口求成员交集，最小时长约束判父窗口，光照细分与成员原弧段是明细；不把它们再次当独立通过窗口。空间纳秒扫描与弹道采样滞回、相切/端点政策保持各自旧规则。

## 精度验证的两个问题

同一物理条件、同一旧模型/源/时刻/采样的迁移精度，按冻结原版及数值黄金验证；新标准载荷启用最小距离、姿态、角速度或太阳约束改变物理条件，另验证正确性，不能拿旧圆锥输出当全球等价结果。本轮旧HTTP、四个CSV及独立传播黄金实测见T29报告；完整15弹道/9空间/21增强空间严格零差及四网页流程见T27/T28对应报告。保留历史C2冷热末位约1–2e-9m与frame 2ULP特定观察、有限并发等范围，不称所有历史差异均消失。
