# 前端载荷配置与弹道窗口接口根路径（T21—T22）

空间「规划工作台」的卫星载荷与「弹道载荷配置」使用同一编辑器、默认值和校验。距离公里，方位/俯仰/太阳半角度，角速度度/秒；LVLH 方位 0° 沿速度方向，俯仰正向背离地球。窗口为矩形姿态约束，不是旧天底圆锥。

空间按卫星分别保存 SPACE/GROUND 长期 profile，点击「保存并启用」只更新当前类型并设为活动载荷；切换类型读取该类已保存值，单纯切换不改变活动类型。历史对地圆锥保留提示，需要用户核对完整参数重新保存，不进行锥角到矩形的伪映射。旧米字段只在历史读取且公里缺失时换算，保存仅发送十个标准字段。

弹道页面从当前目录页及空间已选任务星选择配置卫星，也可新增手工卫星。目录仅提供身份，不含真实根数；轨道数值初始留空，用户必须显式编辑或点击「采用非生产原基准根数」，示例不是目录真实轨道。每星可增删多个独立身份载荷；payloadId 保持稳定、payloadName 可编辑，不复用其他载荷值。窗口计算直接使用同页同一组轨道/载荷草稿。「校验并预览」仍调用真实辅助接口完整回显标准配置。草稿切页保留，刷新不持久化。

每个弹道目标可原生上传 CSV/Excel（.csv/.xlsx/.xls/.xlsm），或显式导入 HTTP/HTTPS 直链、`minio://host[:port]/bucket/object[?secure=true]`（凭据由服务环境提供）。本机路径必须上传；计算的 csvPath 仅为成功上传得到的 serverPath 或已确认的远程地址。换来源/重新上传即清旧引用，上传失败不沿用旧文件；预览原表头/单元格分页不猜未知单位。原文件下载实际 GET 二进制并保留 UTF-8 中文名，网络/服务错误不会下载成假CSV。

根数半长轴米、角度度；目标基准 UTC 留空使用各文件历元，卫星 epochUtc 留空使用原服务 `2026/07/01 10:00:00`。UTC 输入 `yyyy/MM/dd HH:mm:ss[.SSS]` 或 `yyyy-MM-dd HH:mm:ss[.SSS]`，按字面UTC传输，不加减浏览器时区。偏移起点可负；原步长/次数必须正整数，三参数及推导末偏移限定浏览器安全整数范围，末偏移使用 BigInt 精确检查。采样单位秒，<=0 使用原自动步长；三模型 TWO_BODY/J2_SECULAR/J2_NUMERICAL 保留原行为。

计算期间冻结配置，结果绑定实际提交快照；修改输入后明确说明旧快照，任何新计算尝试清旧成功。全部偏移可选择，按真实目标/卫星/载荷/弧段输出展示，累计计数与 best 均来自服务；不补不可见星、去重重算或重新采样。经纬SVG在跨±180°断线，高度图使用原相对秒/米，点表分页只影响显示。point0/全空如实说明。原JSON导出保存HTTP ArrayBuffer原字节，不重新JSON.stringify，保持数值格式、时间与顺序。

| 配置/接口 | 含义与默认值 |
| --- | --- |
| `VITE_API_BASE_URL` | 既有空间完整接口根，默认 `/api/v1/space`；例如 `https://space.example/api/v1/space`。既有语义保持。 |
| `VITE_BALLISTIC_API_BASE_URL` | 新增弹道完整接口根，默认 `/api/v1/ballistic`；例如 `https://ballistic.example/api/v1/ballistic`。不能填空间根，也不拼接到空间变量后。 |
| `VITE_BALLISTIC_COMPUTE_BASE_URL` | 原计算独立完整根，默认 `/api`；例如 `https://compute.example/api`，在该根后拼 `/orbit/visibility/search`，不能填空间根或辅助根。 |
| 弹道预览 | POST `{VITE_BALLISTIC_API_BASE_URL}/payloads/preview`，请求/响应均 payloadId、payloadName 与十标准字段；错误保留 HTTP 400 中文说明。 |
| 文件辅助 | POST `{VITE_BALLISTIC_API_BASE_URL}/files` 使用 FormData/file；GET `/files/{id}/preview?page=1&limit=50` 与 `/files/{id}/download`。 |
| 原计算 | POST `{VITE_BALLISTIC_COMPUTE_BASE_URL}/orbit/visibility/search`，多目标 ballistics、标准多载荷 satellites、原扫描参数；不扩展原计算响应包装。 |
| `VITE_DEV_API_TARGET` | Vite 开发代理后端源站，默认 `http://localhost:8080`；开发下 `/api` 同源转发覆盖空间和弹道，不需要分别改接口根。 |

上述 Vite 变量在启动/构建时读取。生产同源部署可不设置三个接口根；独立源站部署分别设置完整根，并由部署网关/服务处理跨域访问。原文件跨源下载须暴露 `Content-Disposition` 响应头以读取中文名；服务器未暴露时采用默认文件名，二进制仍为原响应。环境文件属本地配置，不提交。

校验规则与 T20 服务一致：距离有限非负且换算米不溢出，max=0不限否则max>min；方位双 null 不限否则 0≤min<max≤360；俯仰双 null 不限，否则 SPACE -90≤min<max≤90，GROUND -91≤min<max≤90；SPACE 跟踪角速度 0/-1 不限、其余非负有限，GROUND 0 是真实零上限且 -1 禁止；太阳半角有限 0..180、0关闭；启动角速度 null/-1 禁用，其他非负有限值仅为元数据。数字框清空明确为 null，必填清空、单端空、倒置窗口和非有限值显示中文并阻止 HTTP，不把空值/NaN 默认成 0，也不把 sentinel 回写为内部极大值。
