# 弹道工作台界面与默认可见窗口整改计划

> **For agentic workers:** 使用subagent-driven-development执行一个A07可验收事项；完成后独立审查完整变更。根独占Git/index/refs，测试失败先修当前项，最终实际核验后更新台账。

**Goal:** 将弹道页面整理为可直接使用的工程计算工作台，移除实现术语和重复解释，并让默认双星示例在保留实际约束和算法的前提下产生真实可见窗口。

**Architecture:** 复用现有Vue草稿、标准载荷校验和真实上传/计算/登记/下载。左侧输入工作区、右侧结果区，默认只展示一组当前卫星载荷；所有弹道子页沿同一紧凑样式。只改前端呈现和明确的非生产示例载荷俯仰，不改后端模型。

**Tech Stack:** Java 8、Spring Boot 2.7.18、Orekit 12.0；原Vue3/TypeScript/ElementPlus/Vite及pnpm锁文件。

## 用户要求与设计决定

用户明确指出界面描述过多、载荷校验/预览无意义、“原窗口扫描条件”无法理解、默认参数0弧段、整体缺乏设计。继续保留“空间的保留不动”和弹道两个一级菜单/拟合三个二级菜单的既有要求。既有授权允许常规实现、测试、提交，无需再询问常规实施许可。

本轮按专业工程软件处理：白色表面、浅灰蓝背景、海军蓝文字、单一蓝色主操作；Microsoft YaHei/Segoe UI，数据用Consolas/tabular-nums，正文14px、标题18px、字段标签13px；8/12/16/24px间距。颜色复用空间语境：#ffffff、#f4f7fa、#20354c、#64748b、#2f689b、#dce5ef。不引入外部字体、装饰图片、营销大标题或新增依赖。

窗口页头仅标题、示例/自定义来源标记和必要操作。桌面采用左侧约60%输入、右侧约40%结果（最小宽度由实际截图校正）；窄屏顺序堆叠。卫星六根数保留表格直接编辑，宽表仅内部滚动；载荷按卫星选择并默认只展开当前一组，避免双星各铺整屏。目标文件区以文件名、点数、历元和上传状态呈现，数据表默认收起；fileId/serverPath/元数据JSON移入可折叠高级详情。计算区称“发射时间搜索”，显示起始偏移/步长/次数和实际末次偏移摘要，积分模型/点输出与采样仍可编辑。

结果区从初始态就有固定位置，未运行给出简短操作提示，运行中明确加载，成功显示服务端原始汇总、候选偏移选择、可见时段表和轨迹操作；0弧段给清晰空态及返回载荷/时间设置的真实操作，不猜测约束淘汰原因。计算按钮在配置区底部固定/粘性可见，单一主动作。表单校验在输入和提交处完成，不需要独立“校验和预览”，不在主流程回显整个配置JSON。

102拟合、模拟、重定时均沿同一视觉规范：任务字段、观测表/端点/源文件、主计算动作、结果；不在常用区写“原服务”“真实201”“outputDir”“DTO”“不冒称”等实现说明。单位、UTC含义和危险编码在简短字段提示/帮助或高级区保留，不能因精简而损失必要语义。10228列与全部兼容输入可访问，JSON高级编辑、别名/字符串保真和文件恢复继续保留。
