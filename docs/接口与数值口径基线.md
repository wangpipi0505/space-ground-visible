# 接口与数值口径基线（T03）

冻结日期：2026-10-13。来源为 T02 的只读空间 backend 与弹道 source 副本。本文只冻结实际契约和后续兼容决策，没有迁入产品业务代码；新辅助接口均为设计契约，尚未实现。结构化出处、声明及 SHA-256 见 `verification/T03/contract-inventory.json`；声明表是原源码而非重新定义的 DTO。

## HTTP 与 Java 的兼容边界

空间共 24 条、弹道共 6 条 Controller 路由。下表逐条列方法、完整路径和原公开签名；参数注解/defaultValue 保留在结构化清单。正常空间接口直接返回原 DTO、数组或 Map，不添加统一 wrapper。弹道拟合/模拟/重定时直接返回 FitRunResult（taskName 字符串、targetCount 整数、files 数组）；每个 FileResult 是 targetId/model/csvPath 字符串、pointCount 整数和 warnings 字符串数组。健康接口空间为 `{status:"UP"}`，弹道为纯文本 `OK`。

空间 IllegalArgumentException 是 HTTP 400 `{code:"INVALID_ARGUMENT",error:字符串}`；未捕获 Exception 是 500 `{code:"INTERNAL_ERROR",error:"服务处理失败",requestId:UUID字符串}`。异步 taskId 为字符串，未知任务 404 空体，未成功结果 409 `{error:字符串}`；删除未知持久化记录 404，删除成功 200 空体。任务状态为 PENDING、RUNNING、SUCCEEDED、FAILED、CANCELLED，迁移不把状态重命名。弹道三个轨迹接口 IllegalArgumentException→400、其他异常→500，体为 `{error:describeFailure字符串}`；visibility/search 是手写错误 JSON 字符串，转义只处理反斜杠和双引号，不能默默改写成功层级。绑定错误、消息转换失败与流式写出失败由实际 MVC 配置决定，不承诺所有错误都具有同一种包体。

空间请求中的 satelliteId/targetId 和列表为 Java Long（JSON 数字）；目录实体 Long 按原 Jackson 注解序列化，结果模型中 observerSatelliteId/targetId 为字符串，持久化结果 id 对外是字符串而路径绑定 Long。stationId、弹道 satelliteId/targetId/payloadId 均为字符串，index/count/offsetSecond 是数字。不得因 JavaScript 精度便利把全部 ID 改成同一类型。时间 Instant 是 UTC；WindowResponse 明确 `yyyy-MM-dd'T'HH:mm:ss.SSS'Z'`，任务 createdAt/completedAt 同样是带Z的毫秒UTC字符串，记录 LocalDateTime 是 yyyy-MM-dd'T'HH:mm:ss.SSS 无Z字符串，不附加时区。VisibilityPlanResponse 正常响应为 results/skippedPairs/totalSkippedPairs/targetFilterBreakdown/ephemerisWarnings/winToolReport；allSkippedPairs 被@JsonIgnore，仅内部持久化使用，skippedPairs最多500条，totalSkippedPairs可大于明细数。保存记录的 requestJson/resultJson/skippedPairsJson/selectionJson 是 JSON 原文字符串，不能改成对象。

分页默认空间卫星 pageNumber=1/pageSize=50，任务记录=1/20，目标查询=1/50；最大 pageSize=200 由服务校验。卫星及站点目录保持原服务排序，任务记录按提交时刻倒序。空间粗步长=60s、细步长=1s；station 前后保护及允许断链缺省取 defaults 服务配置。完整字段/default 表见末尾。

## 弹道请求与响应

VisibilityRequest 默认 ballisticCsvPath=`trajectory-0.1s-standard.csv`、startOffsetSec=-500、stepSizeSec=10、numCalculations=101、sensorFovDeg=140、payloadType=`对地监视`、maxDetectRangeKm=0、sunExclusionAngleDeg=45、targetSampleStepSec=1、trajectoryPointOutput=1、orbitModel=`J2_NUMERICAL`。空卫星列表使用 SAT-A/SAT-B 默认星座，根数 a=7530612m/e=0.00085/i=64.8°/RAAN=120°/近地点幅角=270°，平近点角分别30°/0°，默认UTC历元2026/07/01 10:00:00。显式卫星默认根数相同但 meanAnomalyDeg 缺省0。非空 ballistics 优先多目标；空则旧 ballisticCsvPath 单目标。每个多目标的 baseLaunchUTC、baseLaunchUtc、baselaunchUTC 按原 resolve 方法优先级使用，显式发射UTC优先文件首行参考历元。保留 targetId/targetName、satelliteId/name、payloadId/payloadName 和默认身份生成规则，不能按名称去重。

## 数值、顺序与文件口径

旧弹道 J2000 秒是 UTC 日历 `2000-01-01 12:00:00 UTC` 为0的计数，保留 utcOffsetSec（HTTP入口置0）；不是 Orekit AbsoluteDate.J2000_EPOCH（2000-01-01 12:00:00 TT，对应UTC 11:58:55.816）。同一UTC中午在 Orekit TT J2000 durationFrom 为64.184s，后续时间差还涉及闰秒；绝不能直接把旧秒数作为 Orekit TT历元偏移。旧UTC字符串及毫秒格式按原解析/输出方法保留，空间 ISO Instant 与弹道斜杠UTC不互换。

空间 TLE 用原 SGP4/TEME，六根数传播保留原实现及转换；弹道 ECI 标作 J2000、ECEF 转换使用原岁差/章动/恒星时近似。向量位置m、速度m/s、加速度m/s²、经纬度°、高度m。拟合 ECEF 速度保留 STK Fixed 约定，不能当真实地固坐标导数替换。重定时保存原 ECEF 位置速度，在新时刻重算 ECI；逐行原标记与额外列保留。

弹道二体/J2长期项/J2数值 RK4 三模型保持分立，J2数值最大积分步长30s，拟合区间外二体最大步长1s；空间原RK4默认10s。拟合原始点硬约束、Hermite插值/导数估计/端点修正/外推事件容差都沿用原实现；T03不证明精度，T04建立样本，T10/T15及T27执行同口径回归。

空间太阳为原DE405经TEME转换；原 WGS84圆柱影判定本影，当前没有半影计算，本影豁免太阳规避。弹道太阳方向为解析近似、原可见性始终执行太阳规避。太阳源、阴影豁免和遮挡口径不同，不能为了复用改成同一个源。

allResults 逐 offsetIndex 输出，offset=startOffsetSec+i*stepSizeSec，异步计算按index回填，best 用严格大于累计 double 时长更新，并列保留首次项；不能按完成时间或时长重排。累计时长逐卫星/目标/载荷弧段相加，交叠不做时间并集；若累计非正而点数正，旧回退返回点数；totalObservableSeconds 对 double 四舍五入，但 V2 best 使用 double。finalVisibleWindow 是最早起点至最晚终点包络，可能含不可见间隔，不等于累计时长。LinkedHashMap 保持卫星/载荷/目标首次出现顺序，弧段保持原扫描顺序。稳定弧段至少2点且持续≥1e-3s，退出滞回1e-6°；保留原过滤时机和边界采样，不新增窗口边界插值。

拟合/模拟生成 CSV 按原21列：`YYYY,MM,dd,HH,mm,ss.SSS,ECEF_X,ECEF_Y,ECEF_Z,energy,dt,ECI_X,ECI_Y,ECI_Z,ECI_VX,ECI_VY,ECI_VZ,ECEF_Vx,ECEF_Vy,ECEF_Vz,isOriginal`。日历UTC；位置m，速度m/s；energy=0.5|v|²-μ/|r|（m²/s²），dt为ms，isOriginal原始约束标志。retime读取原header/行顺序/未知列，新增或更新timeIntervalMs（ms），不强制裁切到21列。visibility输入解析保持CSV及XLS/XLSX/XLSM、服务端路径/HTTP/MinIO解析能力；CSV列识别与参考历元优先级不通过全局默认历元覆盖多目标文件。

## 空间标准载荷及旧输出最小兼容方案

弹道 satellites[].payloads[] 在T20引入与空间 PayloadProfileRequest 完全同名的业务字段，payloadId/payloadName继续标识身份：

| 字段 | 空间标准与弹道目标契约 |
| --- | --- |
| payloadType | SPACE/GROUND，统一大小写规范化；旧中文类型继续旧入口解析 |
| minDistanceKm/maxDistanceKm | 公里有限数，内部乘1000变米；min≥0、max≥0，max=0不限，max>0须max>min |
| azimuthMinDeg/azimuthMaxDeg | LVLH方位°；成对null表示不限制，单边null拒绝，0≤min<max≤360 |
| elevationMinDeg/elevationMaxDeg | LVLH俯仰°；成对null不限；SPACE下限-90°、GROUND下限-91°，min<max≤90° |
| angleRateDegPerSec | °/s；保存要求有限值，SPACE 0/-1不限制，GROUND 0是真零上限、-1拒绝 |
| sunAvoidHalfAngleDeg | 太阳回避半角°；有限值及原范围；0按原判据不回避 |
| startupAngleRateDegPerSec | null/-1禁用；其他负值拒绝，0及正值只保存元数据，当前不参与计算 |

旧 /payload 的 minDistanceM/maxDistanceM 继续兼容，不能与公里字段混发；标准profiles使用公里。旧 GROUND 圆锥 profiles 的 sensorFullConeAngleDeg/maxDetectRangeKm/sunExclusionAngleDeg 只在 legacyGroundProfile 回显。旧弹道 maxDetectRangeKm<=0 不限、四类中文载荷的圆锥/环形规则不自动等价为新矩形 LVLH 窗口；旧sensorFovDeg也不能伪装成任意标准窗口。

标准太阳字段可映射旧 sunExclusionAngleDeg 数值，maxDistanceKm映射旧maxDetectRangeKm；最小距离、角速度及LVLH边界没有旧摘要字段。旧圆锥对应条件确实成立时仅回显对应真实锥角；对非圆锥 LVLH 载荷，simpleConeHalfAngleDeg/halfConeAngleDeg/innerConeAngleDeg/outerConeAngleDeg 明确“不适用”，禁止伪造锥角。原摘要锥角默认Double.NaN，经formatJsonNumber已输出null，因此非圆锥标准载荷的四个锥角均置NaN→null，表示“不适用”，保留既有number|null类型，无需新wrapper或伪造0。不能调用旧fromConfig的默认分支替新载荷填57.5°。旧摘要无法完整表达minDistance、LVLH上下限及角速度；最小兼容方案是原响应只保留可真实映射字段及null锥角，标准配置全文由新增辅助预览/配置信息查询返回，不向旧计算响应偷偷加字段。旧中文载荷调用仍保留原摘要值与中文类型；新标准调用按实际SPACE/GROUND标识摘要，属于显式载荷变更。新 minDistance、角速度、太阳或LVLH条件改变物理条件，分别做正确性验证，不能当迁移误差处理；同物理条件才能做原版精度对照。
