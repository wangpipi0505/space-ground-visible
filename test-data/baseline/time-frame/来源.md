# T12 原时间和坐标适配基准

采集日期2026-10-13，Java8 1.8.0_472。采集器是 verification/T12/OriginalTimeFrameProbe.java，类路径只有T04冻结空间/弹道编译类及原依赖，没有加载backend/target/classes。源编译类执行两次，再把弹道类路径替换成原交付plain JAR执行一次，四份JSON三轮全部逐字节相同。源码、原编译类、交付JAR、采集器和JSON摘要见provenance.json。

- legacy-time.json：16个输入×3个utcOffsetSec（0、+28800、−28800），共48条。包括原斜线/横线格式、毫秒、闰年/跨日/跨年、2000年前及非法/空输入的原返回/原异常。正常转换保存原秒、原毫秒/秒格式和往返秒。旧解析/日历的限制没有改成新规则，不能把所有历史日期记录都称为物理正确的通用往返。
- legacy-j2000-ecef.json：3组原J2000位置/速度×6绝对秒，共18条。保存原IAU1976/简化IAU1980/GAST的ECEF位置、含地球自转修正的坐标导数、STK Fixed旋转惯性分量，以及分别对应的反向链。后两种速度含义不同，不能互换。这里用原方法对合成测试向量采集，不是STK实测结果。
- teme-ecef.json：3位置×6UTC Instant，共18条。保存原GroundStationGeometry的TEME/GMST→ECEF及反向位置；Instant包括7纳秒、日/闰年/跨年边界。没有新增原方法不存在的地固速度链。
- eme2000-teme.json：3输入PV×6Instant，共18条。用原Kepler查询的Orekit transformPVCoordinates调用链，保存EME2000→TEME原PV及原UTC AbsoluteDate相对J2000 TT的duration，明确区别于旧日历J2000秒。

JSON中所有double输入/输出使用十六进制字符串；整数case只表示测试组号。原数据用于迁移一致性检查，不能把原实现已知日历范围限制或简化物理模型解释为经过新的精度校准。

实际采集和复核命令记录在 verification/T12/原版采集记录.md；运行目录在忽略的verification/runtime/T12中，黄金与来源摘要是本项目必要回归证据。
