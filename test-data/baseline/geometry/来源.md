# T18 原版几何数值黄金

`geometry.json` 是回归参考数据，不是生产运行产物。由 `verification/T18/OriginalGeometryProbe.java` 独立调用 T02 冻结原空间/弹道实现采集，类路径不包含当前后端。空间使用 T04 Java8 编译类，弹道使用原 classes，并以原交付 plain JAR 替换再比对；重采集全部字节一致。来源与 SHA-256 见 `provenance.json`。

130 对向量包含同侧/穿地、赤道/极区、相切及两侧、端点/inside容差邻近、双内部、同点、极短、零/负零、下溢/溢出、NaN/Infinity、固定随机种子48组；每对另在4个旧J2000绝对时刻采集旋转前后坐标与椭球布尔结果，共520组。所有浮点值以 `Double.doubleToRawLongBits` 的十六进制保存，未作十进制舍入或容差比较。

默认 JUnit 只读取此提交数据。复采必须显式执行 `python verification/T18/capture_geometry.py --frozen-reference`，缺冻结 classes、原 JAR 或依赖路径直接失败，不用当前实现替代原版。该命令保留已有行并核对逐项一致，新增样本不能覆盖旧期望。
