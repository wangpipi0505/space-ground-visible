# T10 原传播状态向量基准

2026-10-13 在新工作目录的 T02 冻结弹道副本中采集。使用 T04 Java 8 编译类、原依赖类路径和本项目 verification/T10/OriginalPropagationProbe.java，没有调用迁入后的传播代码。三个 CSV 源码编译类独立执行两次，再用原交付 plain JAR 执行一次，三轮全部字节一致；源码、编译类、交付 JAR、采集器与 CSV 的 SHA256 见 provenance.json。

- satellite-position.csv：2组根数 × 3个模型 × 12次查询，共72条原公有位置入口输出。
- satellite-j2-state.csv：同样2组根数 × 12次查询，共24条原私有 J2 数值积分状态，包含位置和原积分速度。反射仅用于读取原状态，二体与 J2 长期项的位置接口没有原速度输出，未虚构其速度基准。
- fitter-state.csv：2组原 J2000 端点位置/速度 × 13个 dt，共26条原拟合二体 RK4 私有状态，覆盖1e-5秒不传播阈值两侧、1秒节点、重复/反向/非整步。每次从独立端点状态开始。

首行为字段名，所有 double 输入与输出使用 Double.toHexString，可用 Double.parseDouble 恢复原始数值位；负零仍保留。根数角度为度、半长轴及位置为米、速度为米/秒；卫星历元/绝对秒保持原 UTC 日历 J2000 秒，真实 utcOffsetSec 固定为0。第9列 queryOffsetSec 是原查询相对历元的时间增量，不能作为 utcOffsetSec 或轨道实例标识。拟合 dt 是原相对秒，不经过大历元加减。

卫星查询顺序为 [0,0.125,30,30.125,-0.125,-30.125,60,30.125,3600.375,-3600.375,86400.25,-86400.25] 秒。绝对时刻由原历元加偏移生成，黄金同时保存偏移和实际绝对 double，复验不得从显示时间重新舍入。

采集后的实际核验命令：python -X utf8 verification/T10/verify_original_capture.py；生成两个目录的采集命令及环境记录在 T10 验证报告。这里的原版数值数据为必要回归证据，不属于生产计算结果。
