# 独立 Web 交付

在新 checkout 或仅受 Git 跟踪的副本中，分别运行 `deploy/build.ps1 -Component backend -JavaHome <Java8目录>` 和 `deploy/build.ps1 -Component frontend`。后端使用 Java 8、Spring Boot 2.7.18、Orekit 12.0，前端需要项目锁对应的 Node/pnpm；冻结安装、测试、类型检查失败即终止，不自动升级锁文件。后端不运行前端构建，也不携带历史生成 static。

运行 `deploy/package.ps1 -Destination <不存在的交付绝对目录>`。包中 `backend/server.jar` 与 `frontend/` 是独立产品产物，`orekit-data/` 包含仓库交付数据，`config/application-deploy.yml` 可独立调整。manifest 记录包文件 SHA-256。每次交付使用新目录，不覆盖已运行包。

在任意工作目录执行包内 `start-backend.ps1 -JavaHome <Java8目录> -RuntimeRoot <运行绝对目录> -Port 8080`。运行根包含 database、files/uploads、files/results、files/temp、files/metadata 和 logs；运行数据不得提交。正式默认 MySQL，由环境变量 DB_HOST、DB_PORT、DB_NAME、DB_USER、DB_PASSWORD 配置；Flyway 从 JAR 内 migration 建表。达梦沿用 application.yml 既有驱动和手工 schema 说明。只有验收/演示指定 `-Profile demo`，使用独立 H2，不能当作已验证 MySQL/达梦。Orekit 外置目录不引用原工程。

前端 `frontend/` 交给 Nginx 等静态服务器。`nginx.conf` 提供同源 `/api/` 代理，修改交付绝对路径、端口后运行 `nginx -t`，再启动 Nginx。代理保留路径、上传体积和下载流，不使用 Vite dev server。直接连接 API 的集成方客户端，可指定 `-AllowedOrigins http://frontend.example:8081`；只开放所填确切来源和 `/api/**`，默认关闭跨域。省略该参数时读取外置配置或 `FRONTEND_ALLOWED_ORIGINS` 环境变量，显式传空字符串则覆盖它们并主动禁用跨域。仓库页面仍使用同源 `/api`，推荐反向代理。

服务器需要 Java 8；前端运行仅需要静态 HTTP 服务与浏览器。启动不要求源码 cwd、Swing、桌面选择器或原版目录。停止使用服务管理器正常停止或前台 Ctrl+C，等待 Spring 关闭；进程强制结束不能作为正常关闭证据。
