# 独立 Web 交付

在新 checkout 或仅受 Git 跟踪的副本中，分别运行 `deploy/build.ps1 -Component backend -JavaHome <Java8目录>` 和 `deploy/build.ps1 -Component frontend`。后端使用 Java 8、Spring Boot 2.7.18、Orekit 12.0，前端需要项目锁对应的 Node/pnpm；冻结安装、测试、类型检查失败即终止，不自动升级锁文件。后端不运行前端构建，也不携带历史生成 static。

## 构建工具与运行依赖

T28 干净构建及正式脚本实际验证组合为 Java `1.8.0_472`、Maven `3.9.16`、Node `24.16.0`、pnpm `11.21.0`（Windows PowerShell 5.1）。可采用此组合重现交付；它是已验证配置，不宣称所有其他工具版本都已兼容。前端运行仅需静态 HTTP 服务及浏览器，Node/pnpm 是构建工具。JAR 运行仍必须 Java8；Node24 不改变 Java 版本。依赖仍由 `backend/pom.xml` 和原 `frontend/pnpm-lock.yaml` 确定，不能因工具版本说明升级 Orekit/Spring Boot 或重写锁文件。这落实 T28 审查 Minor M1，实测原命令见 `verification/T28/build-script-all.txt`、`clean-pnpm-install.txt`。

运行 `deploy/package.ps1 -Destination <不存在的交付绝对目录>`。包中 `backend/server.jar` 与 `frontend/` 是独立产品产物，`orekit-data/` 包含仓库交付数据，`config/application-deploy.yml` 可独立调整。manifest 记录包文件 SHA-256。每次交付使用新目录，不覆盖已运行包。

在任意工作目录执行包内 `start-backend.ps1 -JavaHome <Java8目录> -RuntimeRoot <运行绝对目录> -Port 8080`。运行根包含 database、files/uploads、files/results、files/temp、files/metadata 和 logs；运行数据不得提交。正式默认 MySQL，由环境变量 DB_HOST、DB_PORT、DB_NAME、DB_USER、DB_PASSWORD 配置；Flyway 从 JAR 内 migration 建表。达梦沿用 application.yml 既有驱动和手工 schema 说明。只有验收/演示指定 `-Profile demo`，使用独立 H2，不能当作已验证 MySQL/达梦。Orekit 外置目录不引用原工程。

前端 `frontend/` 交给 Nginx 等静态服务器。`nginx.conf` 提供同源 `/api/` 代理，修改交付绝对路径、端口后运行 `nginx -t`，再启动 Nginx。代理保留路径、上传体积和下载流，不使用 Vite dev server。直接连接 API 的集成方客户端，可指定 `-AllowedOrigins http://frontend.example:8081`；只开放所填确切来源和 `/api/**`，默认关闭跨域。省略该参数时读取外置配置或 `FRONTEND_ALLOWED_ORIGINS` 环境变量，显式传空字符串则覆盖它们并主动禁用跨域。仓库页面仍使用同源 `/api`，推荐反向代理。

服务器需要 Java 8；前端运行仅需要静态 HTTP 服务与浏览器。启动不要求源码 cwd、Swing、桌面选择器或原版目录。停止使用服务管理器正常停止或前台 Ctrl+C，等待 Spring 关闭；进程强制结束不能作为正常关闭证据。

## 存储配置及已验证边界

| 配置/环境变量 | 默认与含义 |
| --- | --- |
| `ballistic.files.root` / `BALLISTIC_STORAGE_ROOT` | `storage`；正式脚本改为运行根下 `files`，四个子目录可由 `BALLISTIC_UPLOADS_DIR/RESULTS_DIR/TEMP_DIR/METADATA_DIR` 分别覆盖 |
| `BALLISTIC_MAX_FILE_BYTES` | 67108864 字节；文件本体限额，multipart 请求限额自动加 65536 字节边界空间，勿另设冲突限额 |
| `BALLISTIC_FILE_TTL_MILLIS` | 86400000 毫秒；过期且没有使用租约的文件/登记可被清理，fileId 随之无效 |
| `BALLISTIC_CLEANUP_INTERVAL_MILLIS` | 60000 毫秒；扫描清理间隔 |
| `BALLISTIC_PREVIEW_MAX_ROWS` | 500；默认每页50，预览不改计算采样或原字节 |
| `OREKIT_DATA_PATH` | 正式脚本绑定包内外置 `orekit-data/`；显式Java系统属性 `orekit.data.path` 优先，不改星历文件 |
| `DEMO_DB_PATH` / `LOG_FILE` | 脚本绑定运行根数据库路径及日志文件，运行产物不入源码 |

网页省略 `outputDir` 时，拟合/模拟/重定时各自获得管理结果根内的独占子目录；失败会回滚本次独占输出。显式旧 `outputDir` 仍是服务端兼容路径，但根外文件不能用结果登记接口开放给浏览器。上传和结果下载租约阻止进行中文件过期删除；客户端断开也会释放，登记ID和实际字节仍需校验。完整规则见 `docs/接口使用说明.md`。

T28 已实测独立干净构建、冻结安装、打包、生产静态原字节、同源代理、确切来源跨域及正常关闭；Nginx 未安装，`nginx.conf` 是待集成方 `nginx -t` 的模板。生产 MySQL/达梦未在本机实跑，验收库为隔离 H2。现有生产 chunk 大于500kB提示和 MVC `SimpleAsyncTaskExecutor` 容量提示有记录；有限并发验收不代表无界生产负载。详见 `verification/T28/验证报告.md` 及 T26/T27 报告。
